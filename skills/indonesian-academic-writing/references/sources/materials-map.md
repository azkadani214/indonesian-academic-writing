# Asal Bahan, Adaptasi, dan Rujukan

## Status bahan

Paket ini menyintesis dua bahan teks dan 29 tangkapan layar yang diberikan pengguna. Isinya disunting sebagai pedoman operasional umum, bukan ditranskripsikan seluruhnya atau diperlakukan sebagai ketentuan nasional. Perintah dalam contoh prompt pada gambar dipahami sebagai bahan rujukan, bukan instruksi langsung untuk menjalankan penelitian tertentu.

Dokumen teks pengguna:

1. **Indonesian Academic Writing Style Guide for AI Agent.txt** — dasar pembahasan gaya dan bahasa. Perbandingan umum “AI/Barat” dengan “manusia/Timur” tidak dijadikan fakta universal. Anjuran mempertahankan ketidaksempurnaan diganti dengan penyuntingan bahasa yang benar; angka tidak dihilangkan demi kesan alami.
2. **Pasted text.txt**, diawali “1. Struktur final repository …” — masukan arsitektur. Paket memakai satu skill portabel dan referensi tematik. Daftar slash command di bahan merupakan rancangan, bukan fitur yang otomatis tersedia setelah instalasi.

Nama penulis, tanggal terbit, URL asal, dan lisensi lengkap bahan tersebut tidak tersedia. Jangan membuat metadata bibliografis untuk mengisi kekosongan itu. Pada gambar susunan artikel terlihat identitas Kelas Menulis FU UIN Sunan Gunung Djati Bandung; identitas tersebut tidak otomatis menjadi atribusi bagi seluruh gambar.

## Penyesuaian penting

| Saran pada bahan | Perlakuan dalam paket |
| --- | --- |
| Formula judul tertentu | Alat bantu opsional; disesuaikan bidang dan fungsi judul |
| Rumusan diawali “terdapat” dan minimal tiga pertanyaan | Bentuk serta jumlah mengikuti persoalan dan pedoman |
| Kerangka berpikir sebagai jawaban sementara untuk setiap pertanyaan | Jelaskan alur penalaran; hipotesis hanya bila sesuai desain |
| Teori harus selalu bertingkat | Tidak diwajibkan; gunakan konsep yang benar-benar berfungsi |
| Celah literatur berarti teori belum pernah digunakan | Diperluas ke keterbatasan pengetahuan yang dapat dibuktikan |
| Konteks dan studi lapangan sebagai syarat Sinta 2 | Tidak diadopsi sebagai ketentuan umum; periksa jurnal tujuan |
| Penelitian empiris disamakan dengan eksperimen | Dibedakan; desain empiris dapat noneksperimental |
| Pendahuluan artikel harus satu paragraf | Latihan opsional, bukan aturan semua jurnal |
| Kata kunci harus 3–5 dan alfabetis | Ikuti pedoman tujuan |
| APA 6, 80% jurnal, sumber tiga tahun terakhir | Hanya diterapkan bila diwajibkan atau diminta pengguna |
| Semua judul referensi dijadikan huruf kecil | Diganti kapitalisasi menurut gaya, dengan nama diri dan singkatan terpelihara |
| Memastikan metode telah dilakukan lewat naskah hasil | Perlu bukti pelaksanaan; teks rencana tidak cukup |
| Menjamin judul orisinal atau seluruh literatur belum meneliti | Batasi klaim pada penelusuran dan bukti yang tersedia |
| Membuat temuan terdengar luar biasa | Pertahankan hasil, angka, dan batas klaim tanpa promosi |
| Mengidentifikasi tulisan AI secara pasti | Tidak dipakai; fokus pada kualitas dan transparansi |
